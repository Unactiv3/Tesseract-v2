# DEADPIXEL // Study Hall v2

A slow-burn glitch atmosphere study app. The interface remains functional at all times, but the visual layer accumulates static, screen tears, and pixel noise the longer you stay.

## Features

- Boot sequence with progress bar and jumpscare
- Dashboard with KPIs, task list, and knowledge ring
- Subject tracking with chapter progress
- Notes & Library with corrupted file effects
- Focus Mode (Pomodoro timer with range slider)
- Pixel AI chatbot with keyword responses
- Pixel Lab — find the dead pixel mini-game
- Settings with toggle switches
- **Slow-burn atmosphere escalation** (5 stages over 4 minutes)
- **Idle detection** — eerie but harmless ghost messages
- Fully responsive (mobile bottom bar, stacked layouts)

## Getting Started

```bash
cd deadpixel-v2
npm run dev
```

Open `http://localhost:3002`.

## Tech

Vanilla HTML + CSS + JS. No build step. Google Fonts via `@import`.
